
DewSecure
你的设备，你的规则。

DewSecure 是一款基于设备端 AI 分类器 + 云端联邦学习的用户端内容优化与安全防护引擎。我们不称自己为传统的"广告拦截器"，而是根据用户偏好优化网络资源加载，保护用户免受恶意广告、钓鱼追踪和骚扰弹窗的侵害。所有数据不出设备，隐私完全自主。

“传统工具用昨天的列表拦截今天的威胁，我们用 AI 实时判断。”

⚖️ 法律与合规定位
拒绝“广告拦截器”标签：在法律层面定义为“用户端内容优化与安全防护引擎”。

设备端自主决策：所有过滤决策均由用户设备上的 AI 自主做出。

不提供特定平台规则：工具保持中立，用户自行承担与网站服务条款冲突的风险。

隐私绝对安全：联邦学习架构确保原始浏览数据绝不上传。

### 2. 历史参考 (二分类模型)

| 指标 | 目标 | 实际 | 评价 |
| :--- | :--- | :--- | :--- |
| **F1 Score** | 0.90 | 0.9690 | 优秀 |
| **AUC-ROC** | 0.95 | 0.9883 | 接近完美 |
| **Precision (精确率)** | 0.88 | 0.9875 | 误报率仅 1.25% |
| **Recall (召回率)** | 0.90 | 0.9511 | 漏报率约 4.9% |

为什么对产品而言 Precision 比 Recall 更重要？
误报（把正常网页判成广告）会导致用户网站白屏或功能损坏，引发大量投诉；漏报（漏掉一个广告）仅仅是影响一点体验。我们高达 98.75% 的 Precision 确保了用户上网体验“零破坏”。
