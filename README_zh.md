# DewSecure
**你的设备，你的规则。**

DewSecure 是一款基于设备端 AI 分类器 + 云端联邦学习的用户端内容优化与安全防护引擎。我们不称自己为传统的"广告拦截器"，而是根据用户偏好优化网络资源加载，保护用户免受恶意广告、钓鱼追踪和骚扰弹窗的侵害。所有数据不出设备，隐私完全自主。

> *"传统工具用昨天的列表拦截今天的威胁，我们用 AI 实时判断。"*

## ⚖️ 法律与合规定位
- **拒绝“广告拦截器”标签**：在法律层面定义为“用户端内容优化与安全防护引擎”。
- **设备端自主决策**：所有过滤决策均由用户设备上的 AI 自主做出。
- **不提供特定平台规则**：工具保持中立，用户自行承担与网站服务条款冲突的风险。
- **隐私绝对安全**：联邦学习架构确保原始浏览数据绝不上传。

## ✨ 核心特性
- 🤖 **AI 驱动拦截**：告别繁琐的人工维护规则，利用 AI 实时识别零日威胁。
- 🔒 **联邦学习架构**：在保护隐私的前提下，让模型越用越聪明。
- 🚀 **极致轻量**：INT8 模型 < 50KB，推理延迟 < 5ms，对设备零负担。
- 🛡️ **双引擎驱动**：
  - **规则引擎**：11 万条极速 DNR 网络规则在编译期通过 `build.rs` 压缩为 **FST (有限状态机)**，实现微秒级查询，极低内存占用。
  - **AI 引擎**：设备端智能分类器，专杀未知追踪器。
- 🌍 **多端覆盖**：**Android 系统级防护** + Chrome / Firefox / Edge / Opera 浏览器扩展。
- 💰 **超高性价比**：高级版仅需 $11.99/年（月均不到 $1）。

*(免费版 = 浏览器内的“干净”；高级版 = Android 系统级的“安全”)*

## 🏗️ 底层架构与技术栈
- **Android 客户端 (Kotlin + Rust)**：
  - **smoltcp 透明代理**：脱离传统 VPN 的底层损耗，使用 Rust 手写的用户态 TCP/IP 协议栈，零拷贝、高并发处理 TUN 包。
  - **商业级权限闭环**：Supabase Auth 接入，实时拉取 Pro 权限，Ed25519 签名验签，登出瞬间物理销毁本地 AI 模型，彻底防白嫖。
  - **无缝 OAuth 体验**：采用 Chrome Custom Tabs，配合 Task 栈清理，实现浏览器授权后无残留页面的丝滑登录。
- **浏览器扩展 (MV3 + On-device ONNX)**：共享同一套 AI 权重与 DNR 规则集，极轻量级运行。
- **云原生流水线 (GitHub Actions + Cloudflare R2)**：每日自动训练模型、量化、签名，并安全分发至 CDN 进行端侧 OTA 热更新。
