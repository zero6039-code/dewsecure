# DewSecure

**基于设备端 AI 与联邦学习的用户端内容净化与安全防护引擎。**

## 我们做什么

DewSecure 不是传统的"广告拦截器"。我们是一个**面向用户的安全防护工具**：

- 🛡️ **防御恶意广告**：AI 实时识别恶意广告、钓鱼域名、恶意脚本
- 🔒 **保护隐私**：联邦学习架构，原始数据不出设备，不收集用户浏览历史
- ⚡ **优化性能**：减少网络请求，加速页面加载，节省流量
- 🎯 **内容净化**：移除骚扰性弹窗、漂浮广告、自动播放视频

## 与传统拦截器的区别

| 传统拦截器 | DewSecure |
|:---|:---|
| 规则列表（人工维护） | AI 分类器（自我进化） |
| 需要上传浏览数据 | 联邦学习，数据不出设备 |
| 对付已知广告 | 能识别未知的新型威胁 |
| 拦截工具定位 | 安全防护工具定位 |
